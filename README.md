# Zadanie 7 i 8 - Projekt JavaApi

## Wymagania
* **JDK:** Wersja 11 lub nowsza.

## Konfiguracja biblioteki JSON
1. Pobierz plik biblioteki `json-20250517.jar` (np. z oficjalnego repozytorium Maven Central).
2. Umieść plik w katalogu projektu w lokalizacji: `JavaApi/lib/`.
3. W środowisku IntelliJ IDEA kliknij pobrany plik prawym przyciskiem myszy i wybierz opcję **Add as Library...**, aby umożliwić programowi odczytywanie danych z API w formacie JSON.
